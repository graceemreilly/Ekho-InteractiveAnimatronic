# Ekho-InteractiveAnimatronic
The Ekho Interactive Animatronic is an undergraduate Mechatronics Engineering capstone project completed at CSU Channel Islands. This project incorporates state of the art speech-to-speech AI communication using OpenAI's gpt-realtime-mini model. The full interaction is done implementing a a 3D printed physical model of CSUCI's mascot, ekho the dolphin, prompted (using the Server.js file) to teach children and tell stories about math, science, and Mechatronics Enigneering.
