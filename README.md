# Ekho-InteractiveAnimatronic
The Ekho Interactive Animatronic is an undergraduate Mechatronics Engineering capstone project completed at CSU Channel Islands. This project incorporates state of the art speech-to-speech AI communication using OpenAI's gpt-realtime-mini model in the realtime console. The full interactve cycle is implemented with a physical 3D printed model of CSUCI's mascot, Ekho the dolphin, prompted to teach children and tell stories about math, science, and Mechatronics Enigneering. 

This project was completed by John Higgins, Grace Reilly, Seth Steiminger, and Eric Thornburgh in Fall of 2025 at CSUCI in Camarillo, Ca. 
Advisors: Dr. Bahareh Abbasi, Dr. Vedang Chauhan 




1. Go to https://github.com/openai/openai-realtime-console 
 Follow steps for installation

2. Communication from the RaspberryPi and motors can be found in the config.js program
3. Communication from the controller to the realtime console is in ekho_wrapper.py and ekho-bridge
4. Communication to the realtime console that controls emotion presets fucntion calls can be found in server.js
